# Installing HARA

Download the installer for your computer from the latest [release](https://github.com/ahdmuh/hara/releases/latest), then plug the HARA device into a USB port.

## Mac

1. Open `HARA-<version>-mac-arm64.dmg` on Apple silicon Macs, or the `x64` file on Intel Macs.
2. Drag HARA into Applications.
3. The first time, right-click HARA in Applications, choose Open, then Open again. After that it opens normally.

## Windows

1. Run `HARA-<version>-win-x64.exe`. HARA installs and opens on its own.
2. If Windows shows "Windows protected your PC", choose More info, then Run anyway.

The warnings appear because the installers are not code-signed yet.
